# Adventure Bench releases: lab context

Published benchmark definitions and audited release records.

Lifecycle status and artifact locations are authoritative in [project.yaml](project.yaml). The [project README](../README.md) explains usage and the [agent instructions](../AGENTS.md) define scope and constraints. Setup and routine checks belong to the containing repository; use the project README for reproduction commands.

This is a published snapshot. The related project in the metadata owns ongoing research. Preserve published evidence and record source revisions when exporting corrections.

Record significant decisions under `decisions/` using a dated file with context, decision, and consequences. Later decisions supersede earlier records. Exploratory notes may live under `notes/`, with dates and limitations; neither directory is required until it has content.

Metadata is descriptive, not a claim that experiments are complete or scientifically validated. Routine code changes require no central board update. Existing dated notes and historical decision logs remain evidence of what was believed at the time.
